# 给 AI 的开场白

把下面这段**整段复制**发给新会话，然后等它自己开始。

---

```
读 docs/PLAYBOOK.md，然后按里面的说明启动并开始打。

几条硬要求（手册里也有，这里再强调一次）：

1. 权限必须是 danger-full-access。**先跑 python tools\br-permcheck.py 确认**
   （返回 0 / 显示"权限够"才继续）。游戏要写 %APPDATA%\Godot（工作区外），
   workspace-write 下装是能装成功，但游戏起不来，而且报错长得像 mod 坏了。

2. 读决策点必须用「读文件」的工具（read）读 out/br/need_decision.txt。
   绝不要用 pwsh / Get-Content / type 去读 —— PowerShell 会把中文变成
   「鎴?2 : 搴?2」这种乱码，靠它猜道具名会出错（原会话把「手铐」看成过
   「肾上腺素」，写出一条不存在的 use:adrenaline）。

3. **每个决策点只用这一条命令**：

   python tools\br-next.py "<一句判断>" <decision>
   python tools\br-next.py yes                （选择题：药瓶/菜单/加倍）

   它写决策 + 等下一手 + **把新局面打印出来** —— 一手只花 1 次请求。

   **不要**再 read 决策点（局面已经在它的输出里了）。
   **不要**自己写辅助脚本 —— 已经有两个会话试过，都失败了
   （返回 `ok` 不返回局面，还得再 read 一次，一分钱没省）。
   **不要**用 write 工具写 think.txt / decision.txt（会被文件策略拒）。

4. 决策全权在你，循环不会替你做决定。

5. out/br/lessons.md 里已经有 6 条经验（见下面第 4 节），每手决策点都会显示。
   那些不是命令，是"前人踩过的坑"。先按那些来，打输了自己往里补。

6. 普通模式不要点药瓶，直接开浴室两道门。无尽模式才点药瓶然后选「是」。
```

---

## 它应该做什么

1. 读手册
2. 跑 `python tools\br-launch.py`（会自动起游戏 + 面板 + 主循环 + 对话框抓取器）
3. 反复「read 决策点 → br-set.py 写决策」
4. 打输了往 `out/br/lessons.md` 里补一条教训

## 你怎么判断它做对了

| 观察 | 说明 |
|---|---|
| 它用 `read` 读 `need_decision.txt` | 用 pwsh 读 → 看到乱码 → 猜错道具 |
| 它每条决策只调 2 次工具 | 超过 3 次就是在烧 token |
| 它往 `think.txt` 写话 | 不写的话面板一直显示「deepsleeping」 |
| 决策点里显示「你的教训」 | 说明 `lessons.md` 被正确加载了 |
| 游戏真的动起来了 | 卡住就看 `out/br/run2.log` |

## 它要是卡住

让它跑：

```powershell
Get-Content out\br\run2.log -Tail 20
```

或者查手册第 6 节 / `docs/INSTALL.md` 的故障排查表。

# 📖 关于自带的 lessons.md（重要）

**包里那份 `out/br/lessons.md` 不是空的 —— 里面 6 条是我们打了几十局蒸馏出来的。**

它们覆盖了 AI 最容易犯的几个错：

| 教训 | 解决的问题 |
|---|---|
| 残血优先保命 | 2 血了还硬赌，不回血 |
| 庄家握着逆转器+小刀时，空包也等于2点 | 不知道对面道具的威胁 |
| 写 use:X 之前先核对道具栏 | 编造手里没有的道具 |
| 残血时别把高实弹密度的回合交出去 | 低血时随便交回合 |
| 有电话/放大镜就先读，别拿50%硬赌 | 有情报不用，硬赌 |
| 容错道具先算「能不能把一发变两发」 | 手铐不会用 |

## 三种用法

| 你想要 | 怎么做 |
|---|---|
| **省事**（推荐） | **什么都不做** —— 直接带上这 6 条开始，AI 一上手就比你从头教它快得多 |
| **自己想练** | 让 AI 把 `out/br/lessons.md` 清空（只留格式说明），然后**从零开始** —— 它会自己总结，但那需要很多局 |
| **混着来** | 留几条你觉得对的，删掉你想让它自己体会的 |

**跟 AI 说这句话就能清空重来**：

```
把 out/br/lessons.md 里的教训全部删掉，只保留顶部的格式说明。
之后你自己打，打输了往里面写教训。
```

**注意**：清空之后，AI 会**重演那些坑** —— 不用道具、低血硬赌、编造道具。
这本来就是"从零训练"的代价，想省这个代价就留着。
